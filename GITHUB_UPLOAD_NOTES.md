# GitHub Upload Notes

Recommended public GitHub setup:

1. Create a public repository, for example `file-manager-pro-user`.
2. Push this folder as the repository content.
3. Create a GitHub Release, for example tag `v1.1.0-user`.
4. Upload these files as Release assets:
   - E:\File_Manager_Pro_User_RELEASE_20260616_2350.zip
   - E:\File_Manager_Pro_User_RELEASE_20260616_2350_SHA256.txt

Do not commit the zip directly to the git repository because it is larger than GitHub's normal 100 MB file limit. Use GitHub Releases for the zip asset.
