# File Manager Pro User


**Point it at a messy Windows folder → get back renamed, deduplicated, neatly sorted files, with nothing permanently deleted.**

File Manager Pro User is the portable end-user build for managing, sorting, filtering, renaming, sending to the Recycle Bin and handling duplicate files on Windows.

## Download and run

1. Download the release `.zip`.
2. Extract it into its own folder.
3. Open `File Manager Pro User.exe`.
4. Do not delete the `resources` and `locales` folders or the bundled `.dll/.pak` files, the app needs them to run.

## Main features

- Pick a source folder and scan images, videos and documents.
- `Include subfolders` option to scan subfolders too, or only the current folder.
- Filter files by name, size, created/modified date.
- Sort/export files by type.
- Copy or Move files when exporting results.
- Scan duplicates by SHA-256 hash, file name or file size.
- Copy unique files, separate/move duplicates.
- Export a duplicate files report.
- Batch rename.
- Delete files to the Recycle Bin, never permanently.
- In-app system cleanup:
  - Windows Temp
  - System Temp
  - Windows Prefetch
  - Thumbnail Cache
  - Recent Files List
  - Browser cache
  - Recycle Bin
  - DNS Cache
  - Adobe Premiere / Media Cache
  - CapCut Cache
  - Discord, Telegram, Zoom cache
- English and Vietnamese interface.

## Quick guide

### Scan a folder

1. Click `Select Folder`.
2. Choose the folder to scan.
3. Turn `Include subfolders` on or off as needed.
4. Click `Scan Folder`.

### Filter files

- Use the search box to filter by file name.
- Use the size filter to find small or large files.
- Use the created/modified date filter to narrow down files.

### Export or move files

1. Select the files.
2. Click export/copy.
3. Choose the destination folder.
4. Turn on `Move instead of copy` to move instead of copying.

### Scan duplicates

1. Turn on `Scan duplicate files`.
2. Choose a mode:
   - By Hash: most accurate.
   - By Filename: fast, based on file names.
   - By File Size: fast, based on file size.
3. Click `Scan Folder`.
4. Handle unique/duplicate files with the buttons in the results tab.

### Delete files

1. Select the files to delete.
2. Click the delete button.
3. Confirm in the dialog.
4. Files are moved to the Recycle Bin.

### System cleanup

1. Click `System Cleanup`.
2. Click `Scan size`.
3. Choose the items to clean.
4. Click `Start Cleanup`.

Note: review items marked `CAUTION` carefully before running.
