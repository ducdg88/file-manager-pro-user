# File Manager Pro User


**Trỏ vào một thư mục Windows lộn xộn → nhận lại file đã đổi tên, dọn trùng, sắp xếp gọn, không gì bị xóa vĩnh viễn.**

**Point it at a messy Windows folder → get files renamed, deduped and sorted, with nothing permanently deleted.**

File Manager Pro User la ban portable danh cho nguoi dung cuoi de quan ly, sap xep, loc, doi ten, xoa vao Thung Rac va xu ly file trung lap tren Windows.

## Tai ve va chay

1. Tai file release `.zip`.
2. Giai nen ra mot thu muc rieng.
3. Mo file `File Manager Pro User.exe`.
4. Khong xoa thu muc `resources`, `locales` hoac cac file `.dll/.pak` di kem vi day la thanh phan can de app chay.

## Tinh nang chinh

- Chon thu muc nguon va quet file anh, video, tai lieu.
- Tuy chon `Include subfolders` de quet ca thu muc con hoac chi thu muc hien tai.
- Loc file theo ten, dung luong, ngay tao/ngay sua.
- Sap xep/export file theo loai.
- Copy hoac Move file khi xuat ket qua.
- Quet file trung lap theo Hash SHA-256, ten file hoac dung luong.
- Copy file duy nhat, tach/di chuyen file trung lap.
- Xuat bao cao file trung lap.
- Doi ten hang loat.
- Xoa file vao Thung Rac, khong xoa vinh vien.
- Don dep he thong bang modal trong app:
  - Windows Temp
  - System Temp
  - Windows Prefetch
  - Thumbnail Cache
  - Recent Files List
  - Browser cache
  - Recycle Bin
  - DNS Cache
  - Adobe Premiere / Media Cache
  - CapCut Cache
  - Discord, Telegram, Zoom cache
- Ho tro giao dien tieng Anh va tieng Viet.

## Huong dan nhanh

### Quet thu muc

1. Bam `Select Folder`.
2. Chon thu muc can quet.
3. Bat/tat `Include subfolders` theo nhu cau.
4. Bam `Scan Folder`.

### Loc file

- Dung o tim kiem de loc theo ten file.
- Dung bo loc dung luong de tim file nho/lon.
- Dung bo loc ngay tao/ngay sua de khoanh vung file can xu ly.

### Xuat hoac di chuyen file

1. Chon cac file can xu ly.
2. Bam export/copy.
3. Chon thu muc dich.
4. Bat `Move instead of copy` neu muon di chuyen thay vi sao chep.

### Quet file trung lap

1. Bat `Scan duplicate files`.
2. Chon che do:
   - By Hash: chinh xac nhat.
   - By Filename: nhanh, dua theo ten file.
   - By File Size: nhanh, dua theo dung luong.
3. Bam `Scan Folder`.
4. Xu ly file unique/duplicate bang cac nut trong tab ket qua.

### Xoa file

1. Chon file can xoa.
2. Bam nut xoa.
3. Xac nhan trong modal.
4. File se duoc dua vao Thung Rac.

### Don dep he thong

1. Bam `System Cleanup` / `Don Dep He Thong`.
2. Bam `Scan size` / `Quet dung luong`.
3. Chon cac muc muon don.
4. Bam `Start Cleanup` / `Bat dau Don Dep`.

Luu y: Cac muc co nhan `CAUTION` nen xem ky truoc khi chay.
