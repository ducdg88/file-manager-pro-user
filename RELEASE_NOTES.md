# File Manager Pro User v1.1.0

## Noi dung ban phat hanh

Ban nay la ban User public cua File Manager Pro danh cho Windows portable.

File chay chinh:

```text
File Manager Pro User.exe
```

## Diem moi va diem da khoa an toan

- Tach ten file chay thanh `File Manager Pro User.exe` de khong nham voi ban Admin.
- Ban User khong con mo duoc trang quan ly Admin tu license state cu.
- Neu may tung luu `isOwner: true`, ban User se tu ha ve user thuong khi khong co owner secret dev/admin.
- Xoa file dua vao Thung Rac bang co che an toan, khong xoa vinh vien.
- Them modal Don Dep He Thong trong app.
- Dong bo ngon ngu Viet/Anh cho tinh nang cleanup.
- Giu cac tinh nang chinh: scan folder, filter, duplicate scan, export, move/copy, rename, delete.

## Huong dan cai dat

1. Tai file zip cua release.
2. Giai nen toan bo thu muc.
3. Chay `File Manager Pro User.exe`.
4. Khong tach rieng file exe khoi thu muc, vi app can `resources`, `locales`, DLL va file runtime di kem.
